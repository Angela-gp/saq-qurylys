# Резервная запись демо (2–3 минуты)

Снимайте экран в Chrome или Edge после `make seed` и запуска API/frontend. Убедитесь, что браузерный диалог печати доступен для демонстрации, микрофон выключен, а в демо нет настоящих персональных данных. Для записи выберите средство захвата экрана на компьютере. Это runbook, не записанный видеофайл.

| Время | Действие и фраза |
| --- | --- |
| 0:00–0:20 | Показать пустой обзор до загрузки демо. «На старте нет выдуманных фактов в базе». |
| 0:20–0:35 | Загрузить помеченный ДЕМО набор. «Контрольные сценарии воспроизводимы, это вымышленные данные». |
| 0:35–1:00 | Открыть ЖК сценария B, показать 70 баллов, красную зону и подтверждённые основания. |
| 1:00–1:35 | Создать публикацию с депозитом и бронью на отдельном объекте; показать цитату как гипотезу. |
| 1:35–1:55 | Подтвердить гипотезу и показать изменение 0 → 25. |
| 1:55–2:25 | Создать сигнал, провести на проверку и подтвердить; показать имя автора и время в журнале. |
| 2:25–2:50 | Открыть печать сигнальной карточки; в диалоге выбрать сохранение PDF. |

Фразы держите короткими: система помогает собрать проверяемые основания; она не выносит юридический вердикт. Если браузерный сценарий остановился, покажите сохранённую запись вместо повторного редактирования данных во время защиты.
