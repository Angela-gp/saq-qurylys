# Архитектура SAQ QURYLYS

## Данные

FastAPI выполняет синхронные операции SQLAlchemy 2 с SQLite. В `backend/data/` лежит локальная БД, которая создаётся пустой. Основные таблицы: `housing_objects`, `publications`, `evidence`, `signals`, `audit_log`. Импорт источника создаёт объекты, публикация хранит исходный текст и результат извлечения, а `evidence` связывает наблюдение с фактором и статусом аналитической проверки.

## Поток анализа объявления

1. Аналитик вставляет текст и, при желании, URL и площадку.
2. Извлекатель ищет фразы оплаты локальными правилами или вызывает совместимый с OpenAI API endpoint.
3. Для ответа LLM проверяется, что цитата буквально входит в исходный текст. При отсутствии цитаты гипотеза ненадёжна.
4. RapidFuzz выдаёт кандидатов по названию застройщика или ЖК. Автоматической привязки нет.
5. После ручного выбора объекта приложение создаёт гипотезу R2; R3 предлагается для объекта со статусом строительства.
6. Только действие аналитика `fact` переводит гипотезу в подтверждённый фактор и пересчитывает оценку. Отклонение сохраняется в аудите.

## Источники

`SourceAdapter` задаёт контракт для подключаемых источников. Ashyq адаптер запрашивает только метаданные через публичный API и сообщает о недоступности как `no_data`. Он не трактует отсутствие ответа как отсутствие разрешения. Загрузка набора выполняется из файла CSV/XLSX, который выбрал пользователь. Остальные источники сейчас выведены как ссылки для ручной проверки.

## Оценка и карточка

Модуль `domain/scoring.py` не зависит от FastAPI и SQLAlchemy. Он учитывает только статус `fact`/`confirmed`, ограничивает сумму ста баллами, применяет порог зон и возвращает факторы с источниками. Уникальный код фактора даёт очки один раз. Карточка фиксирует снимок оценки на момент создания; переходы статусов ограничены черновиком, проверкой, подтверждением и возвратом с комментарием.

## API

Основные маршруты: `GET /api/objects`, `GET /api/objects/{id}`, `POST /api/objects`, `POST /api/publications`, `PATCH /api/evidence/{id}/review`, `PATCH /api/objects/{id}/legal-basis`, `POST /api/import/ashyq`, `GET /api/sources`, `GET/POST /api/signals`. Полная интерактивная схема доступна в `/docs`.
