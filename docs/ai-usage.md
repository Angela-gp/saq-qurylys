# Использование ИИ

**Проверено в режиме правил; LLM-режим реализован, но не тестировался с ключом.**

## ИИ-инструменты при разработке

При подготовке прототипа использовался OpenAI Codex как помощник по анализу требований, написанию и редактированию кода, документации и тестов. Проверка агентом включала просмотр кода, автоматические тесты, линтеры, сборку и браузерный прогон чистой установки. Эти проверки не заменяют самостоятельный разбор кода командой. Ответственность за понимание логики, демонстрацию и пояснение принятых решений остаётся у команды.

ИИ помогает находить в тексте объявления языковые фразы о бронировании, депозите, авансе, первоначальном взносе и подобных платежах. Это средство поиска выдержки для анализа, а не система установления нарушения.

## Локальные правила

Локальное извлечение работает без LLM API-ключа. Словари охватывают базовые русские и казахские формулировки. Правила возвращают точный фрагмент из входного текста. Отсутствие совпадения означает только «правила не нашли формулировку». Страница источников отдельно обращается к публичному endpoint метаданных Ashyq.

## Совместимый LLM API

В `.env` можно задать `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL`. Ключ посылается только настроенному endpoint и не сохраняется в базе. Ответ проверяется Pydantic v2; цитата дополнительно должна буквально находиться во входе. При таймауте, ошибке сервера или неверном JSON применяется fallback на правила.

В интерфейсе результат помечен как гипотеза. Аналитик должен проверить контекст публикации и выбрать правильный объект. Подтверждение R2 требует точной цитаты. Факторы не добавляются автоматически только на основании вывода модели. Система не генерирует публичные обвинения или юридические выводы.

Текущая реализация отправляет введённый рекламный текст в выбранный пользователем LLM API только при настроенном ключе. Не вставляйте в форму персональные данные, переписки или документы с ограниченным доступом.

Режим правил тестировался автоматически и на вымышленных публикациях контрольного seed. LLM-режим с настоящим API-ключом и реальным рекламным материалом не тестировался. OCR/распознавания текста с изображений нет.
