# Финальная проверка перед публикацией

Дата: 18.10.2026. Проверка выполнена локально. Владелец разрешил публикацию после дополнительной проверки безопасности. Первичная проверка и дополнительный аудит выполнены до отправки кода в публичный репозиторий.

## Чистая установка

Создан отдельный `git clone --no-hardlinks` в новой папке `saq-submission-*` внутри системного временного каталога Windows. Путь содержит только латиницу. Создан новый venv, зависимости установлены из `requirements.txt`, выполнен `npm ci` с lockfile. База и `.env` основного рабочего проекта не копировались.

После копирования `.env.example` локально сгенерирован SESSION_SECRET. При пустых необязательных полях паролей seed выдал три непустых случайных пароля. В базе созданы только Argon2-хэши. Вход проверен через форму браузера; пароли в этот отчёт и репозиторий не включены.

Найденная ошибка пустого пароля исправлена; добавлен отдельный регрессионный тест. Существующие тесты, формула скоринга и данные A/B/C не изменены. Для интеграционного теста `/signals` нужна production-сборка frontend: это явно указано в README, `make test` теперь сначала выполняет build.

Проверялась production-сборка, раздаваемая FastAPI на отдельном локальном порту, с новой базой.

- Вход аналитика через форму приложения.

- Для отдельного искусственного объекта через форму рекламы отправлен текст о депозите и брони. Проверено буквальное присутствие цитаты и подсветка; до решения балл **0**. Подтверждение R2 через карточку аналитиком даёт **25**, **жёлтую** зону.
- На ширинах **1280** и **1920**, для RU/KK и обеих тем: 8 меток объектов с координатами, видимый балл внутри панели, отсутствие горизонтального и внешнего вертикального переполнения. Проверено увеличение метки при hover строки.
- Ленивый Guided Tour пройден до завершения: 1 → 2 → 4 → 5 → 6 → 8 → 9. Шаг 3 отсутствует при непустой базе; шаг 7 отсутствует у выбранного B без блока ожидающих проверки факторов. Подготовлены **32 снимка**: вход, обзор 1280/1920, реестр, карточка объекта, реклама с гипотезой, источники и сигналы; каждый на RU/KK в светлой/тёмной теме. Подключены из README.

## Сверка поведения

Пилюля демонстрационных данных и нейтральные маркеры отображаются на вымышленных записях; неоценённые реальные записи без подтверждённых фактов показывают «Не оценивалось». В рекламе есть подсветка и уровень уверенности; карточка содержит ручной чек-лист источников. «Не найдено» и «недоступно» не создают R1. Ограничения наблюдателя, автор из сессии, «нет данных ≠ R1», точная цитата, A/B/C и пересчёт проверяются backend-тестами.

Статические строки UI проходят ESLint-правило кириллицы в JSX, а словари — тест равенства ключей и непустых переводов. Имена объектов/организаций, адреса, авторские комментарии и внешние подписи OpenStreetMap остаются данными на языке оригинала; они не переводятся автоматически. Юридический KK-перевод требует проверки носителем языка.

## Источники и ограничения

В `data/raw/` на момент проверки нет реальной выгрузки Ashyq или Telegram `result.json`; эти пункты пропущены. Импорты проверены только на искусственных образцах из `data/sample/`, включая дедупликацию и отбрасывание неизвестных полей Ashyq, фрагменты/пересылки/пустые и служебные сообщения Telegram, пустой и битый JSON. Сами образцы не являются выдержками реальных файлов.

LLM с настоящим API-ключом не тестировался; проверен режим правил. OCR отсутствует. Большинство реестров остаются ручными ссылками. При прошлой попытке скачивания официального CSV Ashyq хост файла не прошёл проверку TLS; обход проверки не применялся.

## Повторный аудит перед публичной публикацией

После разрешения владельца выполнена дополнительная проверка отдельным инструментом Gitleaks 8.30.1: официальный Windows-релиз скачан с GitHub проекта gitleaks/gitleaks, SHA-256 архива сверена с checksums.txt того же релиза. Запущено сканирование всей достижимой истории с `--log-opts=--all`, стандартным набором правил и полной редакцией секретов в отчёте: **no leaks found**, exit 0. Отчёт инструмента оставлен вне репозитория.

Дополнительно проверены все исторические blob-объекты на совпадения с действующими локальными секретами из `.env`: совпадений нет. `tracked-files.txt` точно соответствует индексу (113 файлов). Исторические имена подозрительных файлов: только `.env.example` и прежний пустой `data/raw/.gitkeep`; реальных выгрузок, баз и исходного PDF ТЗ в истории не найдено.

Автор и коммиттер истории — GitHub-профиль `Angela-gp`; используется noreply-адрес GitHub. Содержимое seed просмотрено: 8 записей `is_demo=true`, явно искусственные БИН `000000000001`–`000000000008`, условные названия и учебные адреса. Юридическая уникальность названий по государственному реестру отдельно не устанавливалась. Пароли берутся из локальных env-переменных или генерируются случайно; действующих паролей в коде и README нет.

Повторно визуально просмотрены снимки входа, карточки ЖК, источников, сигналов и оба PDF. Снимки содержат только приложение, без адресной строки браузера, других вкладок или уведомлений; поля входа пусты. Все 32 JPEG проверены на EXIF и комментарии: отсутствуют. В тексте/метаданных обоих PDF не найдены email или личные пути пользователя; авторы в карточках — вымышленные участники seed.

Эти проверки уменьшают риск случайной публикации, но не являются доказательством отсутствия любого возможного вида чувствительных данных.

При первоначальной проверке публикация была заблокирована доступом: gh CLI отсутствовал, GitHub-коннектор требовал повторной авторизации. После этого установлен официальный GitHub CLI 2.102.0 со сверкой SHA-256 архива. Пользователь завершил авторизацию устройства в браузере; пароль и токен в чат не передавались. Создан публичный репозиторий [Angela-gp/saq-qurylys](https://github.com/Angela-gp/saq-qurylys), настроен HTTPS remote. Для публикации выбрана ветка `main`, без force push. Проверка истории Gitleaks повторена перед отправкой.
