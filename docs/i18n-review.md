# Казахские юридические термины для проверки носителем языка

Текущие варианты использованы в интерфейсе и требуют проверки носителем казахского языка, знакомым с правовой терминологией Казахстана.

| Русский термин | Вариант kk | Контекст |
|---|---|---|
| Зона риска | Тәуекел аймағы | Категория аналитического мониторинга (жасыл/сары/қызыл) |
| Сигнальная карточка | Сигналдық карточка | Внутренний документ аналитика, не юридическое заключение |
| Застройщик | Құрылыс салушы | Организация/лицо, указанное в открытой записи |
| Долевое участие | Тұрғын үй құрылысына үлестік қатысу | Термин набора разрешений о привлечении денег дольщиков |
| Правовое основание | Құқықтық негіз | Основание привлечения средств, проверяемое аналитиком |

Переводы русского и казахского интерфейсов централизованы в `frontend/src/locales/ru.json` и `kk.json`; автоматический тест проверяет совпадение наборов ключей и непустые значения. Переведены, в том числе, вход и ошибки, источники, Guided Tour, статусы, формы и сигнальная печать. В README подключены снимки всех страниц на RU/KK в светлой и тёмной темах, а также печатные PDF на обоих языках.

Перевод статусов и пользовательских сообщений всё ещё требует проверки носителем казахского языка, знакомым с правовой терминологией. Следует сверить и предупреждения: приложение показывает сведения для анализа и не присваивает реальным компаниям обвинительные характеристики.
